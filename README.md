# One Line, One Minute: The Funniest AI Excuse

Entry for [One Line, One Minute: The Funniest AI Excuse](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18) — one line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline.

`main.py` (Python stdlib only) writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set).

The line: an AI whose context window got so full of deadline reminders that it evicted the deadline itself to make room for more reminders — machine logic bent into a human-sounding dodge, twist at the end.
